# Fonts

Two typefaces are carried here rather than loaded from Google, so that no
third party sees who opens this app. Both are free software.

- **Inter** — Copyright (c) 2016 The Inter Project Authors
  <https://github.com/rsms/inter>
- **Fraunces** — Copyright (c) 2020 The Fraunces Project Authors
  <https://github.com/undercasetype/Fraunces>

Both are licensed under the SIL Open Font License, Version 1.1, which permits
redistribution and self-hosting provided this notice travels with the files.
The full licence text is at <https://openfontlicense.org>.

Each file is the variable font for one subset, taken from the woff2 Google
Fonts serves, unmodified. `latin` and `latin-ext` only — see the note at the
top of `src/index.css`.
